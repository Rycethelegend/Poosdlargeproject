# Poosdlargeproject - **Poosdalatro**

### Description

A reimagining of the popular digital solitaire game Balatro retooled to work in a fast-paced single-player and multiplayer setting on both browser and android with a live leaderboard.

Hosted using a Droplet on DigitalOcean using a Mern stack, on an Ubuntu Linux Server with nginx, express PM2, and MongoDB database. 

Created for COP4331C, Processes in Object-Oriented Software Development at UCF, Fall 2026.

# Setup Instructions

Once your server and database are set up you can use the frontend/api here to deploy your app on a domain of your choice.

## Server setup

### Step 1: Server creation
- Create an Ubuntu 24.04 LTS server with a hosting provider of your choice. Create keys to use with SSH.
- Use a package manager of your choice to install these globally (we used NPM):
  - Node / NPM
  - Express / PM2
  - MongoDB
  - Mongoose
  - Dotenv
  - Nginx

### Step 2: Cloning the repo:
- Navigate to ~/var/www/
- Run: git clone https://github.com/Rycethelegend/Poosdlargeproject.git
    - Alernatively, fork the repository and use that link instead.
- Navigate to Poosdlargeproject/
- Run: npm install
- Navigate to frontend/
- Run: npm install
- There should be no errors, and all packages should be up to date.

### Step 3: Environment variables
- .env files are not cloned with the repo. You must make a new one:
- Run: vim .env
- Paste this text:

```c
// Insert mongoDB connection URI after database creation in section 2:
MONGODB_URI=mongodb+srv://${USERNAME}:${PASSWORD}@${ACCOUNT_DOMAIN}.puafigd.mongodb.net/${DB_NAME}

// Generated by JWT Token. Must paste here afterward.
ACCESS_TOKEN_SECRET=${LOTS OF LETTERS AND NUMBERS}

// Get this info from the SMTP Provider/Host of your choice.
SMTP_HOST=smtp.sendgrid.net
SMTP_PORT=2525
SMTP_USER=${SMTP_USERNAME}
SMTP_PASS=${SMTP_PASSWORD}
MAIL_FROM="${EMAIL_TITLE} <${FULL_EMAIL_ADDRESS}>"
```

### Step 4: Generating key pairs
- For automatic deployment, github actions requires a private key, and the server requires a public key.
- On the server, run:
  - ssh-keygen -t ed25519 -C "github-actions" -f ~/.ssh/github_deploy -N ""
- Navigate to the ~/.ssh folder
- Copy the private key with:
  - clip < ~/.ssh/colors_lab_deploy
- Hold this in your clipboard, it will be used in the next step.

### Step 5: GitHub Actions workflow
- The server is automatically built and deployed using main.yaml inside .github/workflows/
  - This happens every push, and every pull request/merge
- Log into your github, and navigate to your cloned/forked repository.
- Navigate to repository settings, then to repository secrets
- Enter the following secrets. Capitalization is critical here:
  - SSH_HOST: Your hosting server IP (on DigitalOcean, it's IPV4)
  - SSH_KEY: Private key you just copied
  - SSH_USERNAME: SSH username (on DigitalOcean, it's "root")
  - DATABASE_LINK: MongoDB connection URI, created later in section 2 (database setup).

### Step 6: Verify build and deployment
- All pieces should be in place. Change the README.md, commit that file, and push using:
  - git push -u origin main
- The workflow should now run. Give it 5 minutes, and check for errors.
- If successful, the built website should appear under ~/var/www/html/.

### Step 7: Nginx
- Navigate to /etc/nginx/sites-available
- Paste this:

```c
server {
        listen 80;
        listen [::]:80;

        root /var/www/html;
        index index.html;

        server_name cop4331-5.com www.cop4331-5.com 209.38.68.57;

        location / {
                try_files $uri $uri/ /index.html;;
        }
}
```

### Step 8: Start backend
- Navigate back to ~/var/www/Poosdlargeproject/
- Run: pm2 start server.js --name "express-server"
- Run: nginx restart
- Run: pm2 startup
- Run: pm2 save
- Run: sudo ufw allow 5000
- The server is now ready.
  
## Database Setup

### Step 1: Login/Sign up to MongoDB Website
- Go to MongoDB website and create an Account or Sign into one:
- Use this link: https://cloud.mongodb.com/

### Step 2: On MongoDB, Create a Project
- In your project, create a Cluster called `Poosdbase`
- Inside of the `Poosdbase` Cluster, create a database called `PoosdDatabase`

### Step 3: Making the Schema
- In the `PoosdDatabase` create 4 tables:
  - `Leaderboard`
  - `Rooms`
  - `Users`
  - `VerificationCodes`

**Use the Entity-Relationship Diagram in this GitHub's `docs/poosdatabase_erd-v4.png` file to see what each table's entries should look like.**

### Step 4: MongoDB User Connection
- Make sure you create a database user for PoosdDatabase with Read & Write permissions.
- Make sure you remember its Username and Password for later connection steps.

### Step 5: Connecting Database to Server
- In your Env file and Github Secrets, replace the value for `DATABASE_LINK` with your database link.
- Your database link should look like: `mongodb+srv://{Username}:{Password}@poosdbase.puafigd.mongodb.net/PoosdDatabase`
- Where `{Username}` and `{Password}` are replaced with your Username and Password for the database user created in Step 4.

**Note: This `DATABASE_LINK` variable is used in the `server.js` file.**

**Note: The `server.js` file uses the mongoose Node.js library to connect to MongoDB.**

## Mobile App Setup

### Step 1: Install Flutter and Android Studio
- Download and install Android Studio: https://developer.android.com/studio
- Download and install Flutter: https://docs.flutter.dev/get-started/install
- In Android Studio, go to Settings → Plugins and install the `Flutter` plugin.

### Step 2: Finish the Android Setup
- In Android Studio's SDK Manager, install `Android SDK Command-line Tools`.
- Open a terminal and run `flutter doctor` to check that everything is installed.
- Run `flutter doctor --android-licenses` and accept the licenses.

### Step 3: Open the Mobile App
- Clone this GitHub repository.
- In Android Studio, go to File → Open and choose the `mobile` folder inside the repository.
- When asked, click `Pub get` to download the app's packages.

### Step 4: Run the App
- Start an Android emulator from the Device Manager, or connect an Android phone with USB debugging turned on.
- Select the device and press Run.
- Log in, or create an account in the app.

### Step 5: Install the App on a Phone (Optional)
- In a terminal inside the `mobile` folder, run `flutter build apk --release`.
- Copy `app-release.apk` from `mobile/build/app/outputs/flutter-apk/` to your phone and open it to install.

**Note: Make sure to open the `mobile` folder, not the top folder of the repository, or Android Studio won't recognize the app.**

**Note: The app connects to the server at `https://poosdbasecontactmanager.casa`. If you host your own server, search the `mobile` folder for this address and replace it with yours.**
